# NRG Property Solutions website

Static, responsive website for GitHub Pages.

## Files
- `index.html` — page structure and content
- `styles.css` — visual design and mobile layout
- `script.js` — mobile navigation, year, estimate-request form

## Publish on GitHub Pages
1. Create a GitHub repository (or open the existing website repository).
2. Upload these three files to the repository's root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.
6. GitHub will show the published website URL in Settings → Pages.
