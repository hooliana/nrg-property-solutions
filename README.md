# NRG Property Solutions Website

A responsive static website for NRG Property Solutions.

## Files
- `index.html` — website content
- `styles.css` — design and responsive layout
- `script.js` — mobile navigation and estimate-message form
- `images/fall-cleanup.jpg` — user-provided fall cleanup photo
- `images/snow-removal.webp` — user-provided snow removal photo

## Publish with GitHub Pages
1. Upload all files and the `images` folder to the root of your GitHub repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` and folder `/ (root)`, then save.

The estimate form opens a pre-filled text message to the business phone number. The visitor must press Send; the website does not store submissions.

The residential yard gallery uses Unsplash-hosted images. Replace them with NRG's own job photos as they become available.
